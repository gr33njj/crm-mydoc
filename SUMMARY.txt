================================================================================
                         БЫСТРЫЙ СТАРТ (15 мин)
================================================================================

1️⃣  Получите Telegram Bot Token от @BotFather

2️⃣  Настройте окружение:
    cd /root/crm-mydoc
    cp .env.example .env
    nano .env
    # Заполните SECRET_KEY и TELEGRAM_BOT_TOKEN

3️⃣  Подготовьте сервер:
    chmod +x setup-server.sh
    ./setup-server.sh
    # Перезайдите после выполнения!

4️⃣  Запустите деплой:
    chmod +x deploy.sh
    ./deploy.sh

5️⃣  Создайте администратора:
    make admin

6️⃣  Готово! Откройте https://crm.it-mydoc.ru

================================================================================
                          API ENDPOINTS (основные)
================================================================================

Auth:
  POST   /api/auth/register    - Регистрация
  POST   /api/auth/login       - Вход
  GET    /api/auth/me          - Текущий пользователь

Tasks:
  GET    /api/tasks            - Список задач (фильтры)
  POST   /api/tasks            - Создать задачу
  GET    /api/tasks/{id}       - Получить задачу
  PATCH  /api/tasks/{id}       - Обновить задачу
  POST   /api/tasks/{id}/complete  - Завершить задачу
  POST   /api/tasks/{id}/comments  - Добавить комментарий

Chat:
  GET    /api/chat/rooms       - Комнаты чата
  GET    /api/chat/rooms/{id}/messages  - Сообщения
  POST   /api/chat/rooms/{id}/messages  - Отправить сообщение

Reports:
  POST   /api/reports          - Сгенерировать отчёт
  GET    /api/reports/{id}     - Получить отчёт
  GET    /api/reports/{id}/download  - Скачать отчёт

                         МАСШТАБИРУЕМОСТЬ

Система готова к масштабированию:

• Горизонтальное: Несколько инстансов backend за load balancer
• Вертикальное: Увеличение ресурсов контейнеров
• База данных: PostgreSQL read replicas
• Кэш: Redis Cluster
• Статика: CDN
• Мониторинг: Prometheus + Grafana (готово к добавлению)
